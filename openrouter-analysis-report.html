如何理解数据口径

使用规模、推理性能和厂商份额分别对应需求侧、供给侧和竞争结构。不同指标需要在各自有效窗口内比较。内嵌日期包含相邻日记录，因此观测点数不能直接等同于独立周数；进一步分析需要核对抓取频率、统计周期及滚动窗口是否重叠。

飞轮①数据飞轮：使用规模持续扩张

OpenRouter 是生成式 AI 的「流量枢纽」——主流平台模型经其分发。周度总 token / 请求量直接测度「用户与模型互动产生的数据量」，即飞轮的输入端。窗口 2026-06-29 ~ 2026-09-20。
周度总 token（十亿，左轴）周度总请求（百万，右轴）
📈 在 63 周窗口内，周度总 token 增长 2.33 倍、请求量增长 1.75 倍，活跃路由模型由 365 增至 426+。使用规模的指数级扩张 = 互动数据持续积累 = 飞轮输入端不断放大。

使用增长与数据飞轮

请求量更接近交互频次，Token 量还受到输入长度、输出长度和任务结构影响。Token 增长快于请求增长，可能反映平均处理长度增加或模型组合变化。流量增长提供产品改进的潜在机会，但不能证明数据已经用于训练；数据权限、反馈质量和训练流程决定其能否转化为模型质量提升。

飞轮②平台 token 份额：头部厂商争夺数据入口

同一窗口内，按 top_models 模型 token 求和得到的各厂商份额演化（Top 10）。谁占据流量入口，谁就掌握飞轮最稀缺的「使用数据」。
🔄 份额呈「多强并立 + 高频轮动」：头部由 openai / google / anthropic / deepseek / xiaomi 等交替领跑，说明数据入口竞争远未固化，飞轮红利仍在再分配。

流量份额的解释

份额是相对指标，份额下降时厂商绝对用量仍可能增长。模型上线、价格调整和路由策略也会影响短期分布。模型子集与全平台份额的分母不同，应分别解释。流量轮动描述使用结构变化，不能直接证明数据所有权或议价能力变化。

性能①推理性能长期改善：效率竞争的底线抬升

对全部 2025-07-07 ~ 2026-09-21（161周） 周的性能模型取中位数 p50 延迟与 p50 吞吐。延迟下行、吞吐上行，反映算力配置与推理工程的整体进步——这是飞轮「输出端」（更好体验→更多使用）的硬件基础。窗口 2025-07-07 ~ 2026-09-21。
中位数 p50 延迟（ms，左轴，越低越好）中位数 p50 吞吐（tok/s，右轴，越高越好）

性能改善的边界

延迟影响等待时间，吞吐影响生成速度。中位数能减弱极端观测的影响，但不同任务、上下文长度和并发负载仍会产生体验差异。跨期变化也可能包含样本替换的影响；更严格的比较需要追踪固定模型，并控制请求条件和测量方法。

性能②最优供给方之争：推理基础设施成为独立战场

同一模型在不同供给方上延迟/吞吐差异巨大。best_latency_provider / best_throughput_provider 统计「在多少模型上该供给方是最优」。这是平台/云厂在「算力资源配置」上的直接较量。

最优「吞吐」供给方（累计上榜模型数）
🏗️ 延迟之战 DeepInfra 领先（1491 次最优），吞吐之战 Alibaba 领先（1009 次最优）。中国云厂在推理效率上占据优势——性能竞争已超出「模型能力」，延伸到算力调度与供给方生态。

最优供给方如何比较

上榜计数同时受到性能、模型覆盖和观测次数影响。覆盖更多模型可能带来更多获胜机会，因此计数不等于全面领先。实际服务选择还应比较价格、稳定性、速率限制和具体模型表现，单一榜单不足以支持对整个云服务行业的普遍判断。

🧲 最新周 Top3 厂商合计约 65.34% 流量，HHI≈1752.9（中等集中度）。头部集中明显但非寡占——这正是飞轮「强者愈强」正反馈与「新进入者仍能突围」并存的证据。

集中度与竞争结构

HHI 为各参与者份额平方的总和，按百分数计算时最高为 10000；Top3 份额反映前三家合计占比。解释前应确认全部厂商是否纳入、剩余份额如何处理及分母是否一致。集中度描述流量分布，不能单独证明市场支配力或数据飞轮的因果机制。

质量设计竞技场质量榜（飞轮产出端）

最新基准日 2026-09-07 的 design-arena「website」类目 ELO 评分 Top 模型。质量提升是飞轮的正反馈终点：更好模型→更多使用→更多数据。
ELO 评分为 LMArena 式相对评分（越高越强）。模型名取自基准列，厂商归属因命名差异未完全映射。

质量评测与后续研究

ELO 是特定评测环境下的相对评分。website 类目主要反映网页生成任务，不能直接推广至所有模型能力。检验数据飞轮需要将使用量、质量、性能和价格置于一致的时间框架，区分模型升级、供给优化和需求变化。当前结果提供描述性研究线索，尚未完成因果识别。
